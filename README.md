# efoo.jp

efoo株式会社のコーポレートサイト https://efoo.jp/ （WordPress）を、手元のパソコンで動かして改善するためのリポジトリです。

## 手元でサイトを動かす

Claude Code などの AI エージェントでこのリポジトリを開き、「ローカル環境を起動して」と頼んでください。手順は `AGENTS.md` に書いてあり、エージェントがそれに従って準備します。

起動すると、本番と同じ内容のサイトが次の URL で開けます。

- サイト: http://localhost:8890/
- 管理画面: http://localhost:8890/wp-admin/ （ユーザー名 `admin`、パスワード `password`）

手元のサイトで何を変えても、本番の efoo.jp には反映されません。安心して試せます。

## 準備が必要なもの

- OrbStack か Docker Desktop（起動しておく）
- 本番の内容を手に入れる手段（次のどちらか）
  - 本番サーバーへの SSH 接続の許可。管理者に公開鍵を登録してもらう
  - 管理者から受け取ったバックアップのフォルダ
